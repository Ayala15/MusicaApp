MusicaApp - app de música minimalista (Kotlin + Jetpack Compose)

- Catálogo, portadas y audio: API de Deezer (https://api.deezer.com), sin API key. Solo vistas previas de 30 s.
- Recomendaciones: API de ReccoBeats (https://api.reccobeats.com/v1/track/recommendation), sin API key.
- Modo claro/oscuro: botón de sol/luna arriba; se recuerda la elección.
- Cuentas y canciones guardadas: solo en el dispositivo (SharedPreferences).
  La contraseña se guarda como hash PBKDF2 con sal, no en texto plano.
